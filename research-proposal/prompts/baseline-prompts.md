# Group A — Baseline Vanilla Prompts
Direct task instruction without explicit constraint decomposition, acceptance criteria, or continuity rules. This is the baseline control group.

## Example 1: Solution Planning
> Please write an executable project plan for the given task brief: {task_brief}

## Example 2: Multi-turn conversation
> Respond to the user's latest message. Conversation history: {history}
> User message: {user_message}

## Example 3: Video storyboard
> Write storyboard prompts for this creative brief: {video_brief}
