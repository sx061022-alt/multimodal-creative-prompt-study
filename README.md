# Multimodal Creative Prompt Study
Graduate thesis project | Non-commercial academic research
This repository hosts research plans, prompt datasets, evaluation scripts, and experimental records for my study on multimodal creative tasks.

## Research Overview
This work focuses on prompt engineering, aesthetic prompt generation for AI video, and robustness evaluation of GPT-4.
I will test multi-round prompting workflows, build multimodal evaluation pipelines, and analyze model output quality.
Fine-tuning will be performed on GPT-4 to calibrate its preference for creative aesthetic standards and structured planning logic.
GPT-3.5 is excluded due to inherent limitations in long-chain reasoning and aesthetic judgment.

## Intended OpenAI API Usage
- Prompt testing & ablation experiments
- Multimodal output quality assessment
- Dataset construction for creative video prompt generation
All API usage is limited strictly to academic research, no commercial use.
